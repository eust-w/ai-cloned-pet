# Alpha Launch Kit

## Position

Photo-to-companion workbench for creative developers. The source is inspectable, interaction playback is local, and model services are optional at runtime. This is an independent experiment, not an official Codex product and not a mature 3D clone.

Do not promise star counts, exact likeness, realistic motion, personality cloning, or zero total API cost. Initial image generation and optional vision/LLM calls may be billed by the configured provider. Do not publish private photos, credentials, local paths, or example sprites from other creators in the source release.

## Video

Record the real interface with `node scripts/record-demo.mjs`. Render horizontal and vertical captioned cuts with `DEMO_PHOTO=/approved/local/photo.jpg node scripts/render-launch.mjs`. Both scripts use local files and the local app only. Review the output for clipping, misleading cuts and image artifacts before posting. These cuts are silent, not narrated.

The sequence is: real Coco photo, pointer approach, petting feedback, local rest command, English UI, limits/cost, repository link. Never portray the existing generated asset as a fresh generation captured on camera.
