# Asset Policy

MIT covers project source and documentation. It does not grant rights to local user uploads, generated pet images, third-party branding, fonts, music, or promotional video files.

- Original pet media stays in `.data/storage/originals` and is excluded from source packages.
- Generated sprites stay in `.data/storage/avatars` and depend on input rights and provider terms.
- Browser traces, logs, screenshots, and release videos stay in ignored local artifact directories.
- Add a media example only with its own provenance and explicit redistribution license.
- Coco is a private real-media test subject, not a bundled public sample or benchmark ground truth. A promotional draft using Coco does not make its source photos available for reuse.
- The reference spritesheet supplied for visual guidance is not bundled or relicensed.

Record the media owner, approved platforms, intended uses, and applicable provider terms before publishing a campaign. Inspect recordings for private paths, messages, credentials, and unrelated windows.
