# Release Gates And Roadmap

## Alpha Positioning

An experimental, local-first photo-to-companion workbench. A useful first audience is creative developers who want personalized 2D companions. Stars are an outcome of usefulness and repeat use, not a release guarantee.

## Before A Public Alpha

- [x] Clean source package with no credentials or personal media; scan source and Git history.
- [x] Fresh Node.js 24 install, build, tests, and real browser interaction evidence.
- [x] Dependency audit reviewed with no unexplained high/critical findings.
- [x] README and video script describe transformed pose cells honestly.
- [ ] Maintainer reviews license/asset boundaries and the release diff.
- [ ] Decide target accounts, public repository visibility, and final video/caption approval.

## Before A Broad Product Launch

- [ ] True action-specific frame sequences with a consistent character and articulated motion.
- [ ] Alpha, silhouette, clipping, identity, and motion checks before activation; failed assets must not become the default.
- [ ] Saved generation sources and retry per failed action, with request/cost visibility.
- [ ] Stable interaction priorities, interruption, quiet mode, keyboard/touch access, and responsive bounds.
- [ ] Portable pet package import/export and a rights-cleared example that works without a provider key.
- [ ] Reproducible clean install on macOS and Linux; document Windows status separately.

## Later

Optional desktop shell, creator-contributed action packs, and more provider adapters. Public hosting is a separate effort requiring account isolation and cost controls. 3D, voice cloning, emotional diagnosis, and real-animal behavior prediction are not promised.

## Distribution

Publish one verified alpha release first. Demonstrate the same real interaction in Chinese and English. Invite focused contributions on known gaps; measure completed installs, successful first-avatar generation, repeat usage, and useful issues before setting reach or star targets.
