# AI Cloned Pet

把自家宠物的照片，变成能在浏览器里回应你的卡通伙伴。

[English](README.md) · [开发路线](docs/ROADMAP.md) · [参与贡献](CONTRIBUTING.md)

**当前为实验版 Alpha。** 已接通真实照片输入、头像生成和浏览器互动；动画质量仍在完善。当前生成器生成 9 张姿态图，再通过位移、缩放和旋转拼成 72 个单元，并非 72 张独立的肢体动画帧。项目是 2D 虚拟宠物，不提供 3D 重建，也不能克隆真实宠物的性格或意识。

## 已有能力

- 上传自己的宠物照片；视频在本地用 ffmpeg 抽取静态图片。
- 绘本、软萌立体画风、像素、水墨线稿四种形象风格。
- 点击场景靠近、点击宠物触发反馈、使用本地文字指令。
- 缓存精灵图，本地播放和基础互动不反复请求模型。
- 中文默认，支持英文切换。
- SQLite 本地存储、元数据导出和媒体删除。

仓库不附带 API Key、真实宠物照片、生成资产或预置宠物。首次启动为空。音频目前仅可上传保存，尚未实现声音理解或克隆。

## 本地启动

准备 Node.js 24 和 npm；上传视频还需要 PATH 中有 ffmpeg。

```bash
git clone https://github.com/eust-w/ai-cloned-pet.git
cd ai-cloned-pet
npm ci
cp .env.example .env
npm run dev
```

打开 http://127.0.0.1:5173，创建宠物并确认素材授权，然后上传照片。生成形象前，在 `.env` 配置自己的模型服务。配置示例、费用边界和开发指令见 [英文文档](README.md)。

`npm run build` 构建前后端，`npm start` 仅启动编译后的 API；另开终端运行 `npm run preview` 预览生产构建的网页。

## 费用与数据

本地抽帧、缓存播放、点击和本地文字指令不调用模型。画像分析调用视觉模型；一次头像生成当前调用 **9 次图像 API**；勾选 LLM 后的文字互动调用语言模型。模型服务自行计费，不承诺永久免费。

原始媒体存储在本地。分析时选中的图片、生成时的参考图会发给你配置的提供方；LLM 规划会发送画像和文字消息。生成结果下载到本地缓存。请只上传有权使用的素材。

## 现阶段边界

- 整图形变不能替代真实的行走、眨眼或摇尾逐帧动画；抠图和身份一致性仍需完善。
- 备用照片图集只是把照片分配到动作槽位，不识别照片里的动作。
- 本地文字规划是规则匹配；自由对话需开启 LLM。
- 当前是无认证的本地单用户应用，不适合直接暴露公网。
- 3D 接口已关闭；JSON 导出不包含媒体文件本体。
- 项目独立开发，与 OpenAI/Codex 无官方关联，尚未验证其宠物格式导入兼容性。
